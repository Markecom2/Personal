# Command Desk

Personal daily dashboard that pulls Zoho Mail, Slack and Monday.com into one urgency-ranked list,
with a Claude-written plan per item and an inline reply box.

Live (private) page: https://claude.ai/artifact/Y8jo3pGAqTFY6ieQKNjvy1

`index.html` is the source of that page. It only works when opened as a claude.ai artifact, because it
reads data through the viewer's claude.ai connectors (Zoho, Slack, monday.com) and asks Claude for plans.
Opened as a plain file it shows example data.
